# Working on ngai_tunes

- Preserve the [product contract](docs/SPEC.md) when changing behavior.
  Update it when a change intentionally alters that contract.
- Follow the [architecture](docs/ARCH.md) when assigning responsibilities
  across the client, daemon, audio engine, and storage.
- Follow the [UI style guidelines](docs/STYLE.md) when changing the TUI.
- Keep changes focused and cover behavior changes with unit tests.
